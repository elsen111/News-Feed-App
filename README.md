# 🌐 Novatra News — React News Aggregation Web App

Novatra News is an interactive and personalized news aggregation web application built with React.  
The app displays trending and user-relevant news articles with dynamic search, filtering, saved articles, and responsive design.

---

## 🚀 Purpose

The main purpose of this project is to provide users with a smooth and personalized news browsing experience.

Users can:

- Browse latest news articles
- Search news dynamically
- Filter articles by category
- Save favorite articles
- Continue using saved preferences across sessions
- Explore more articles using Load More functionality

---

## 🛠️ Tech Stack

- React
- JavaScript ES6+
- HTML5
- CSS3
- Fetch API
- LocalStorage
- JSON
- Netlify

---

## ✨ Features

- Dynamic news feed
- Personalized “For You” section
- Real-time search functionality
- Category-based filtering
- Saved articles using LocalStorage
- Load More functionality
- Responsive design for desktop, tablet, and mobile
- Clean and modern UI
